## 3. 新功能清单（0.2.2-rc.1 官方发布说明，按相关度排序）

### 3.1 与本机使用强相关

| 项 | 说明 |
|---|---|
| 手机/平板适配 | 软键盘交互、导航、窄屏布局全面优化（手机远程操作 DSH 受益） |
| 修「部分结构体代码高亮导致页面长时间卡死」 | 页面假死类问题 |
| 全局与项目 AGENTS.md 分别用 maxBytes 预算 | 以前项目指令会挤掉全局指令；现在两条链各自有预算（`global.md` 卡告警线时有用） |
| 系统提示词未变时继续复用前缀缓存 | 降成本（缓存命中 0.1 vs 未命中 1 元/百万 tokens） |
| 插件管理支持更新第三方插件包 + 热更新失败自动回滚旧版本 | 自研插件发布链路受益 |

### 3.2 通用新功能

- **变更请求与工作树**（实验性）：独立 Git worktree 里跑会话，可搜索文件树 + 逐文件看本地/PR 差异，选中代码与评论直接交给 Agent
- **会话文本引用**：聊天文本作引用插入输入框，发送后紧凑预览
- **完整历史会话复制为 Markdown**（带原始日志路径）
- **工作步骤收起后保留全部助手回复**，可切「仅最终回答」
- **统一右键/键盘菜单**（会话、工作区、侧边栏），开发者可扩展
- **文件预览常驻目录树 + 文件定位**
- **subagent_oar 工具**（实验性）：独立任务交给本机 Codex 或 Claude CLI
- **开发者工具·统计**（实验性）：按轮次/步骤看上下文、缓存、模型与工具耗时
- **个性化推荐**（实验性）
- 新增日/西/法/德/俄/巴葡 6 套语言

### 3.3 体验细节

侧栏会话悬浮卡显示工作目录 · 同名工作区显示最短区分路径后缀 · 消息宿主确认接收后才显示并清空草稿（发送期间输入框只读、失败保留草稿）· 图片进输入框即上传且单张上限 50 MiB · 中键关右侧栏标签 · 远程连接默认开 WebSocket 压缩 · 静态资源支持 ETag/304 · 模型选择器默认勾选已配置模型并支持批量增删 · 自动化任务页可一次清除全部已结束任务 · Search 优先给长摘要（每来源默认 800 字符）· Trajectory 可看工具返回值原始 JSON、子调用独立折叠

### 3.4 开发向破坏性变更（官方原文要点）

- Node.js 最低 **24.9**；Cordis Core **4.1.0** / Loader **1.1.0** / Include **1.1.0**；pi-ai **1.3.0**
- `agent/request` **不再允许改路由**，插件改用 `agent.model`
- 插件需迁移 `tools.resolve` / `executable` 与提示词组装接口
- Session Projection 注册 API **异步化**，需插件启动时持有
- 原生与 PTC 工具执行拆为**按 Agent 作用域选择**的插件；旧 `tools.mode` / `DSH_TOOLS_MODE` 需迁移
- PTC 控制通道改 **birpc**；自部署 bootstrap 与 SSH helper 必须同步升级（SSH 协议 **2 → 3**）
- PTC 取消分类：`run_code` 由调用方取消返回 **ABORTED**（原 `CODE_RUN_FAILED`）
- 官方组合包列表改由 `@deepseek-ai/dsh-official-bundles` 导出，自定义集成需更新原 app-boot 导入
- **文件修改「先读 / 外部修改防护」默认关闭**（需要原防护的 profile 显式恢复观察策略）
- 未声明容量的自定义模型默认上下文/最大输出改为十进制 **1M / 128K**
- profile `dsh.profile.bundles` 需移除 `@deepseek-ai/dsh-experimental-tool-worktree`（已合入「变更请求与工作树」）

## 5. 将来真要升级时的前置检查清单

### 5.1 升级前（DSH 还开着也能做）

```powershell
# ① 整目录备份（重点：记忆库）
Copy-Item "$env:USERPROFILE\.dsh" "$env:USERPROFILE\.dsh.bak-pre022-$(Get-Date -Format yyyyMMdd_HHmm)" -Recurse
# ② 只读体检
cd ~/.dsh/patches
node widen-plugin-peers.mjs
node reveal-native-path/apply-rc2.mjs check
node frontend-static-nocache/apply.mjs check
node katex-strict-silence/apply.mjs check
# ③ 记录基线（端口 / remote authority / 记忆库条数）
```

### 5.2 升级后第一件事（在跑补丁之前）

1. **核对 `$DSH_HOME` 没被重置** —— `~/.dsh/memory/.memtopic/mem.db` 还在、主题数对得上（当前 575 条）
2. **核对监听端口**（0.2.1 起随机分配）与 `.dsh-remote\.harness-cookie.json` 的 `authority` 是否同步
3. 核对 `~/.dsh/profiles/*/cordis.patch.yml` 自定义条目还在（`ui-aqua`、`dsh-memory`、`dsh-memory-client`、`dsh-subagent-default`、`computer-use*` …）

### 5.3 补丁重放（顺序固定，见 runbook §7.1）

```
widen-plugin-peers.mjs --apply
reveal-native-path/apply-rc2.mjs apply-global → apply-asar
frontend-static-nocache/apply.mjs apply-global → apply-asar   ← 需先改好 0.2.2 锚点
katex-strict-silence/apply.mjs apply
→ verify ×3 → 重启 → 人工验收
```

### 5.4 手工项

- computer-use / cua-driver-native 两包 bump 到 `0.2.2-rc.1` + `pnpm install` + 热启用
- 从 profile `dsh.profile.bundles` 移除 `@deepseek-ai/dsh-experimental-tool-worktree`
